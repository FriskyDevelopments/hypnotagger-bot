# 📱 iPhone Quick Start Guide

## 🚀 Deploy Your Bot in 5 Minutes

### 1. 📱 Open GitHub on iPhone
- Visit `github.com/YOUR-USERNAME/hypnotagger-bot`
- Tap **"Code"** → **"Codespaces"** → **"Create codespace"**
- Wait 2 minutes for setup

### 2. 🎯 Deploy to Railway
```bash
# In Codespaces terminal:
npm run deploy
```

### 3. ✅ Test Your Bot
- Message your bot on Telegram: `/start`
- Submit a video: `/submit [YouTube URL]`
- Try KinkScout: `/scout_guide`

## 🎭 Quick Commands

```bash
npm run check     # Check deployment status
npm run deploy    # Deploy to Railway
npm run iphone    # iPhone development info
npm start         # Run bot locally
```
