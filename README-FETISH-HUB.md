## 🆘 Troubleshooting

### Bot Not Responding

1. Check `.env` configuration
2. Verify bot token and permissions
3. Ensure all dependencies installed
4. Check system logs for errors

### Curator Commands Not Working

1. Verify user ID in curator lists
2. Check channel permissions
3. Ensure bot has admin rights in target channels
4. Review permission levels

### Content Not Distributing

1. Verify channel IDs are correct
2. Check bot permissions in channels
3. Ensure content is properly tagged
4. Review error logs in curator room
